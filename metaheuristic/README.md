# PSO for path planning

Folder code: file main.py chạy mô hình mô phỏng trong pygame quá trình tìm đường của 3 robot , file mpl là mô phỏng bằng matplotlib, file plot dùng để khảo sát các thông số và vẽ biểu đồ.

Folder figure: chứa ảnh khảo sát các siêu tham số với 3 tham số đánh giá là cost, độ dài lenght, số lần hội tụ và thời gian chạy các vòng.
